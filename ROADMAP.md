# План развития форка

Цель форка — дать `gopusher` предсказуемый Go-аналог русского склонения из
`pymorphy2==0.8`, сохранив возможность перейти на актуальные словари и
поведение `pymorphy3` после отдельной проверки совместимости.

## Этапы

1. **Зафиксировать контракт совместимости.** Составить корпус слов и чисел из
   Python-рендеринга, отдельно отметить различия словаря и различия алгоритма
   выбора формы. Критерий готовности — воспроизводимый отчёт с объяснением
   каждого расхождения.
2. **Стабилизировать API и жизненный цикл.** Использовать явный конструктор,
   кэшировать анализаторы по пути словаря и не связывать `Parse` с глобальным
   экземпляром. Критерий готовности — несколько независимых анализаторов и
   корректная ошибка загрузки одного словаря не влияют на другой.
3. **Сделать работу из нескольких горутин безопасной.** Убрать изменяемые
   общие коллекции из пути `Parse.Inflect` и добавить проверки под race detector.
   Критерий готовности — `go test -race ./...` без предупреждений.
4. **Добавить дифференциальный тестовый контур.** Генерировать ожидаемые формы
   Python-реализацией и сравнивать их с Go на фиксированном корпусе. Критерий
   готовности — тест показывает отдельно ошибки реализации, версии словаря и
   намеренные изменения контракта.
5. **Определить поставку словаря.** Зафиксировать версию OpenCorpora, способ
   обновления файлов и обязательные лицензии для исходников и данных. Критерий
   готовности — чистая сборка пакета без ручного копирования словаря.
6. **Подключить к `gopusher`.** Заменить набор ручных форм макроса на библиотечный
   вызов с безопасным fallback, метриками и проверкой обоих рендереров. Критерий
   готовности — паритет макроса в Python и Go на общем корпусе.
7. **Подготовить релиз.** Описать публичный API, ограничения и совместимость,
   затем выпустить версию форка после прохождения тестов и проверки лицензий.

## Выполнено в первой итерации

- добавлен `NewMorphAnalyzer` для независимых экземпляров;
- `GetMorphInstance` кэширует экземпляры по абсолютному пути;
- внутренние анализаторы больше не используют глобальный `morphAnalyzer`;
- `Parse` хранит владельца-анализатор для `Inflect`, `Lexeme` и `IsKnown`;
- кэш граммем защищён от гонок и наружу выдаётся копия;
- добавлены проверки жизненного цикла и конкурентного склонения.
